## Опис завдання (Варіант №4)

На основі номера залікової книжки **5108** розраховано варіант завдання:
* **C11:** $5108 \pmod{11} = 4$ — Визначити клас **Одяг** (Clothing), який складається мінімум з 5-ти полів.

### Вимоги до роботи:
1. Створити клас із закритими полями та доступом через гетери/сетери.
2. Створити масив об'єктів цього класу.
3. Відсортувати масив за одним полем за зростанням, а за іншим — за спаданням (використовуючи стандартні засоби Java).
4. Реалізувати пошук об'єкта в масиві, який повністю ідентичний заданому, за допомогою методу `equals`.

## Структура проєкту

* `src/main/java/lab3/Clothing.java` — Клас-модель. Реалізує принципи інкапсуляції, перевизначає методи `toString()` для виводу та `equals()` для глибокого порівняння об'єктів за значеннями їхніх полів.
* `src/main/java/lab3/Main.java` — Головний клас. Створює масив об'єктів, демонструє роботу сортування (через `Comparator`) та логіку пошуку.
* `src/test/java/lab3/ClothingTest.java` — Юніт-тести (JUnit 5) для перевірки коректності методу порівняння об'єктів.

## Логіка реалізації

* **Сортування:** Виконано за допомогою `Arrays.sort()` та `Comparator.comparing()`. Це дозволяє гнучко налаштовувати критерії сортування (наприклад, спочатку за ціною, потім за брендом).
* **Ідентичність:** Метод `equals` був спеціально перевизначений, щоб порівнювати не адреси в пам'яті, а реальний вміст полів (назву, розмір, ціну тощо).
* **Пошук:** Реалізовано через лінійний перебір масиву, де кожен елемент порівнюється із "цільовим" за допомогою нашого методу `equals`.
