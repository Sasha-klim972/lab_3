## Особливості реалізації

Головною вимогою цієї роботи є використання класу `StringBuffer` замість `String`.
У проєкті реалізовано:
* **Ручний парсинг тексту:** Замість стандартного методу `split()`, який повертає масив `String`, текст розбивається на слова посимвольно за допомогою `charAt()`.
* **ООП підхід:** Логіка обробки винесена в окремий клас `TextProcessor`.
* **Сортування:** Використано кастомний `Comparator` для об'єктів `StringBuffer`.
* **Обробка виключень:** Використано блоки `try-catch` для обробки можливих помилок (наприклад, порожній вхідний текст).
* **Тестування:** Логіка покрита Unit-тестами (JUnit 5).

## Структура проєкту

* `src/main/java/lab2/TextProcessor.java` — клас із логікою обробки тексту.
* `src/main/java/lab2/MainLab2.java` — вхідна точка програми.
* `src/test/java/lab2/TextProcessorTest.java` — модульні тести.
